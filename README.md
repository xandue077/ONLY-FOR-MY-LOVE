# Love Test 💜 — xandue edition

A small purple love story website for GitHub Pages.

## Pages
- `index.html` — love test. The **That's my answer 💜** button opens `memories.html`.
- `memories.html` — three clickable surprise boxes.
- `song.html` — photo + music page.
- `days.html` — automatically counts relationship days.
- `letter.html` — love letter for Leena.

## Relationship day counter
The counter is currently set so:
- August 22, 2026 = Day 1
- August 23, 2026 = Day 2
- August 24, 2026 = Day 3
- August 25, 2026 = Day 4

To change the starting day later, edit `START_DATE` near the bottom of `days.html`.

## Add your song and photos
Put these files inside `assets/`:
- `our-song.mp3`
- `song-cover.jpg`
- `song-photo-1.jpg`
- `song-photo-2.jpg`
- `song-photo-3.jpg`

The music page is set to autoplay when possible, but some phones/browser settings can block autoplay. There is always a play control available.

## GitHub Pages
Upload everything inside this folder to your repository, keeping the `assets` folder next to the HTML files.
Then use **Settings → Pages → Deploy from branch → main → / (root)**.

The QR code on the main page automatically uses the current website URL.
