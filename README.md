# Purple Love Website 💜

Upload the files to GitHub Pages.

## Assets
Put these files inside `assets/`:
- `cute-love.gif` — the animated GIF on the main pages
- `our-song.mp3` — the song
- `song-cover.jpg` — the small image shown to the left of **Sweet Boy**
- `our-days.jpg` — the photo shown on the Day Counter page

The Day Counter is configured so August 22, 2026 is Day 1, August 24 is Day 3, and it increases automatically each day.
